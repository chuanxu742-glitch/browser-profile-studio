# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting or a private Security Advisory for vulnerabilities that could expose browser profiles, cookies, API keys, proxy credentials, 2FA secrets or local network resources. Do not open a public issue containing secrets, working exploit payloads or data copied from a real browser profile.

Include the affected version or commit, reproduction conditions, expected impact and the smallest safe reproduction you can provide. Remove all real account data before attaching logs or profile samples.

## Scope

The current `main` branch is supported. Security fixes are not guaranteed to be backported to older commits or locally modified browser cores.
